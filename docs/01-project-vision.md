# Project Vision

## Project Name

**EventHorizon**

---

## Overview

EventHorizon is an open-source full-stack observability and incident investigation platform.

The system is designed to simulate a distributed software environment where multiple services continuously generate logs. Those logs are collected, indexed, searched, and analysed through a modern web interface, allowing engineers to investigate failures and understand how incidents propagate across services.

---

## Problem Statement

Modern software systems consist of many independent services running simultaneously.

When an error occurs, engineers often need to analyse thousands of log entries produced by different services before identifying the root cause.

EventHorizon aims to simplify this process by providing a platform capable of collecting, organising and exploring large volumes of log data.

---

## Objectives

The main objectives of this project are:

- Learn modern full-stack software engineering.
- Design a production-like software architecture.
- Build a scalable backend using Python and Flask.
- Develop a React frontend for data visualisation.
- Store application data in PostgreSQL.
- Index and search logs using OpenSearch.
- Containerise the application using Docker.
- Prepare the project for OpenShift deployment.
- Apply software engineering practices including testing, documentation and version control.

---

## Target Users

The platform is intended for:

- Software Engineers
- Backend Engineers
- DevOps Engineers
- Site Reliability Engineers (SRE)
- Students interested in distributed systems

---

## Long-Term Vision

The long-term goal is to evolve EventHorizon into a realistic engineering project that demonstrates software architecture, distributed systems, observability, and modern development practices through a fully open-source implementation.
