# EventHorizon

EventHorizon is an open-source observability and incident investigation
platform for ingesting, indexing, searching, and correlating logs produced
by distributed services.

## Planned technology stack

- Python
- Flask
- JavaScript and React
- PostgreSQL
- OpenSearch
- Docker and Docker Compose
- OpenShift
- Git and GitHub

## Initial objective

The first version will generate synthetic service logs, ingest them through
a Flask API, index them in OpenSearch, and display searchable results through
a React interface.

## Project status

Early development.
